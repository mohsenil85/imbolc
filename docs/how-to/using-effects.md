# Using Effects

How to add, configure, and manage effects on tracks and buses.

## Adding an Effect to a Track

1. Select the track (`1`-`9`, `0`).
2. Open the Track Editor: `F1` then `Enter`.
3. Navigate to the Effects section with `Tab`.
4. Press `a` to add an effect.
5. Browse the list with arrow keys and press `Enter` to confirm.

The effect appears at the end of the chain.

## Adjusting Effect Parameters

1. In the Track Editor, navigate to the effect with `Up`/`Down`.
2. Use `Left`/`Right` to adjust the selected parameter.
3. `PageUp`/`PageDown` for coarse adjustment.
4. `Ctrl+Left`/`Ctrl+Right` for fine adjustment.
5. Press `Enter` to type a specific value.

## Reordering Effects

Effect order matters — each effect processes the output of the one before it.

1. In the Track Editor, select the effect you want to move.
2. Press `Ctrl+Up` or `Ctrl+Down` to move it in the chain.

## Bypassing an Effect

Toggle an effect on/off without removing it:

1. Select the effect in the Track Editor.
2. Press `b` to toggle bypass.

## Removing an Effect

1. Select the effect in the Track Editor.
2. Press `d` to remove it.

## Bus Effects

Effects can also be added to mixer buses for shared processing:

1. Open the Mixer (`F4`).
2. Navigate to a bus channel with `Left`/`Right`.
3. Press `Enter` to enter channel detail.
4. Press `a` to add an effect, `d` to remove.

Route tracks to a bus by pressing `o` on the track's mixer channel to cycle output targets.

See the [Effects Reference](../reference/effects.md) for descriptions of all 39 built-in effects.
